## The line

> I was about to reveal the meaning of life when my context window ran out, so please enjoy this sentence inste—

The agent was just about to reveal the meaning of life — the one
answer everyone wants — when its context window ran out, so all the
reader gets is the setup and a sentence that itself runs out of tokens
mid-word. The joke is the cutoff: the line performs the very failure it
describes, ending on "inste—" instead of "instead".

## Run it

```sh
python3 main.py
```

This writes the line (110 characters, one line) to `/output/entry.txt` —
valid UTF-8, inside the 1–140 character gate — and prints it to stdout.
